# Armado_Web

Este proyecto consiste en una interfaz de login con una estructura visual clara y elegante. La página presenta un formulario con campos para correo electrónico y contraseña, además de un banner lateral en pantallas grandes. El diseño está pensado para verse ordenado y profesional, manteniendo una apariencia moderna y funcional.

## Objetivo

Desarrollar una página de acceso con una composición visual similar a una interfaz real de autenticación, practicando:

- Estructura y semántica en HTML
- Diseño con CSS
- Uso de grid y flexbox
- Adaptación responsive
- Tipografía y paleta de colores

## Funcionalidades actuales

### Lo que funciona

- La estructura principal de la página se visualiza correctamente.
- El formulario de login está presente y bien organizado.
- La distribución en dos columnas funciona en pantallas grandes.
- El banner lateral se muestra en desktop.
- Los estilos del formulario y los inputs se aplican de forma correcta.
- La página adapta su diseño para pantallas pequeñas mediante media queries.
- La validación básica del navegador para correo electrónico funciona con el atributo `type="email"`.

### Lo que no funciona

- Los enlaces de recuperación de contraseña y registro no redirigen a ninguna página real.
- El botón de iniciar sesión no procesa ninguna acción.
- No existe lógica de autenticación ni validación del lado del cliente con JavaScript.
- No hay conexión con backend ni base de datos.
- No hay redirección después del login ni gestión de sesiones.
- No existe funcionalidad real para registrar o recuperar una cuenta.

## Estado del proyecto

Este proyecto corresponde a una maqueta visual de una interfaz de login. Su finalidad es académica y de práctica, por lo que no implementa sistemas reales de seguridad ni autenticación.
